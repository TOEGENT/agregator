# Структура БД

Итоговая БД сохраняется в pickle и состоит из трёх словарей:

```python
db = {
    "catalogs": {
        "root": {
            "title": "Каталог",
            "children": ["5428"],
        },
        "5428": {
            "title": "Электроинструмент",
            "children": ["5440"],
        },
        "5440": {
            "title": "Дрели-шуруповёрты",
            "children": ["5441"],
        },
        "5441": {
            "title": "Ударные",
            "children": ["card:12345"],
        },
    },
    "cards": {
        "card:12345": {
            "name": "Ударная дрель Makita",
            "images": ["image.webp"],
            "description": "Описание товара",
            "stats": {
                "Мощность": "710 Вт",
            },
        },
    },
    "reverse": {
        "5428": "root",
        "5440": "5428",
        "5441": "5440",
        "card:12345": "5441",
    },
}
```

## Правила

- Ключ каталога — стабильный ID каталога на сайте поставщика.
- Название не используется как ID, потому что названия могут повторяться.
- `catalogs[id]["children"]` содержит ID непосредственных потомков.
- У промежуточного каталога потомками являются подкаталоги.
- У конечного каталога потомками являются карточки.
- Префикс `card:` отличает ID карточки от ID каталога.
- Все данные карточек лежат отдельно в `cards`, поэтому поиск проходит только по `cards.items()`.
- `reverse[child_id] = parent_id` хранит обратную связь для каталогов и карточек.
- Хлебные крошки строятся подъёмом по `reverse` от карточки до `root`.
- URL страниц каталогов и карточек нужны только парсеру и в итоговую БД не сохраняются; ссылки на изображения остаются в `images`.

## Заполнение

1. Парсер собирает ID, название и временный URL каждого каталога.
2. ID подкаталога добавляется в `children` родителя.
3. Одновременно записывается `reverse[child_catalog_id] = parent_catalog_id`.
4. Для конечных каталогов парсер загружает карточки.
5. Данные карточки записываются в `cards[card_id]`.
6. ID карточки добавляется в `children` конечного каталога.
7. Записывается `reverse[card_id] = catalog_id`.
8. Временные URL удаляются, после чего `catalogs`, `cards` и `reverse` сохраняются в pickle.

Пример восстановления пути для найденной карточки:

```text
card:12345 -> 5441 -> 5440 -> 5428 -> root
Ударная дрель Makita -> Ударные -> Дрели-шуруповёрты -> Электроинструмент -> Каталог
```
